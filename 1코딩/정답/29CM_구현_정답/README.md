## 코드 기준

→ HTML·CSS 작성 기준: `1코딩/모나미/index.html`, `style.css`
→ 모나미 HTML에 등장한 태그와 CSS 초기화에 포함된 제목·문단 태그를 사용합니다.
→ 모나미 style.css에서 사용한 CSS 속성만 사용합니다. 합본의 style 태그는 정리 형식입니다.
→ 세로는 기본 블록 배치, 가로는 display:flex / justify-content / align-items / gap으로 구성합니다.
→ 여러 줄 목록은 행을 나눕니다. flex-wrap과 flex-direction을 추가하지 않습니다.
→ 글꼴은 기존 모나미 font 폴더의 Pretendard 400/500/700입니다.
→ 학습 참고 주석은 실제 모나미 파일을 가리키며, 정답 코드에만 있는 문법을 기준으로 삼지 않습니다.
